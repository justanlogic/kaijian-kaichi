# 隐私与数据

## 默认：只在本机

- 训练、饮食、身体数据、目标与推荐资料，默认写入浏览器的 `localStorage`，键为 `kjkc.state.v1`。
- **不登录不会发起任何数据上传。**
- 不接广告、不埋点、不接第三方统计、不保存密码。

## 可选：云同步

登录后才会同步，用于手机与电脑之间换设备：

- 两种入口：WorkBuddy 登录、微信登录；两者相互独立，数据不互通。
- 云端每个账号一行 JSON 快照，表为 `app_states`。
- 行级安全策略（RLS）只允许 `owner_id = auth.uid()` 的读写，客户端不发送 `owner_id`。
- 登录后本机修改约 **1.6 秒**防抖上传；离线时排队，联网重试。
- 本机与云端都有数据时，**不会静默覆盖**：让你选择「从云端恢复」或「上传本机」。
- 退出登录后停止同步；本机数据保留。

## 导出、清空与撤销

- 设置页可导出完整 JSON 备份；导入前会校验结构，坏文件不会覆盖本地数据。
- 导入后 10 秒内可撤销；清空需输入「清空」两个字才能提交，执行前自动写入快照，10 秒内可撤销。
- 删除单条记录也可撤销。

## 浏览器存储不是备份

以下情况仍可能丢数据：

- 手动清除该站点的浏览数据或缓存；
- 使用无痕 / 隐私模式；
- 卸载或更换浏览器、更换设备；
- 系统存储空间极度紧张时浏览器主动清理；
- iOS Safari 对长期未访问的站点可能回收脚本存储。

建议：

1. 把应用安装到桌面 / 主屏幕，持久化存储更容易获批；
2. 每月在「设置 → 导出备份」保存一份 JSON；
3. 换设备时用「导入备份」恢复，或登录后同步。

## 云端数据的删除

当前版本没有「删除云端快照」的按钮。需要删除时：

- 先退出登录，停止后续同步；
- 在仓库开一个 Issue（不要贴任何个人数据），说明需要删除云端快照；
- 维护者会按账号标识处理。

## 演示模式

- 入口：`?demo=1`。
- 会注入一份示例数据（70kg / 15% 体脂），仅用于展示。
- 如果检测到本机已有非演示数据，**不会覆盖**，只提示「本机已有数据」。
- 演示数据带 `demo: true`，刷新会重置；点「清除并退出」会移除示例数据。

## 数据所有权

你的记录属于你。项目不声称对用户数据拥有任何权利；导出文件可自行迁移到其他工具。

有隐私相关的疑问或建议，欢迎开 Issue（请勿在 Issue 中粘贴真实健康数据）。
