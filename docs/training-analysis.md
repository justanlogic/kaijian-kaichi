# 训练分析口径

训练页的「训练分析」读取最近 **28 天**的训练记录，给出完成情况、容量趋势、动作表现、部位覆盖和下一步建议。它看的是训练安排是否在推进，不是给动作质量或伤病下结论。

> 结论基于你记录的数据，不替代教练判断；如有疼痛、伤病或持续不适，请先咨询专业人士。

## 数据来源

| 数据 | 用途 |
| --- | --- |
| 训练日期 | 训练天数、每周频率、活跃周数 |
| 动作名称 | 动作级趋势、部位覆盖 |
| 每组重量与次数 | 总容量、最高重量、PR、平均每组重量 |
| 设置里的每周训练次数 | 完成率参照；未设置时按每周 3 天 |

`训练天数` 指有训练记录的不同日期数，不等于动作条目数。一天记 3 个动作仍然算 1 个训练日。

## 四个维度

### 1. 完成情况

- 4 周目标 = 每周目标次数 × 4；默认目标为每周 3 天，页面会标注「按每周 3 天参考」。
- 完成率 = 训练天数 ÷ 4 周目标。
- 活跃周 = 4 个 7 天区间里有训练记录的周数。

### 2. 训练趋势

- 把 28 天切成 4 个 7 天区间，分别统计训练天数、总容量、总组数。
- 趋势 = 后两周（第 3–4 周）与前两周（第 1–2 周）比较。
- 有负重时用总容量；全是自重时自动改用总组数。

### 3. 表现变化

- **力量 PR**：某次训练的最大重量超过该动作历史最大重量时计一次；只统计有负重的动作。
- **平均每组重量**：所有负重组的总重量 ÷ 总组数，比较前后两周。
- **动作级趋势**：每个动作按「每次训练平均容量/组数」比较前后两周，避免因为某个动作这两周练得少而误判为下降。
- **最高重量变化**：后半段最高重量减前半段最高重量。

### 4. 优势与不足

优势可能来自：

- 完成率 ≥80%；
- 总容量/组数上升 ≥10%；
- 有 PR；
- 平均每组重量上升 ≥3%；
- 某个动作容量上升 ≥10%；
- 覆盖 ≥4 个训练部位。

不足可能来自：

- 完成率 <60%；
- 总容量/组数下降 ≥15%；
- 8 次以上负重训练没有 PR；
- 某个动作容量下降 ≥10%；
- 只训练 ≤2 个部位，或缺胸/背/腿中的一项；
- 平均每次 <6 组；
- 最近 >10 天没有训练；
- 单一部位或单一动作占训练量 >60%。

最多各展示 3 条。

## 总体结论

| 结论 | 触发条件 |
| --- | --- |
| 数据不足 | 训练 <4 天，或活跃周 <2 周 |
| 建议调整 | 完成率 <50%（已设目标）、容量/组数下降 ≥30%，或最近 >14 天没训练 |
| 需要关注 | 完成率 <80%、趋势下降 ≥10%、8 次以上负重训练无 PR，或只覆盖 ≤2 个部位 |
| 稳步推进 | 其余情况 |

## 数据不足时

- 少于 4 个训练日：提示还差几次训练；
- 少于 2 个训练周：提示还需要跨一个训练周；
- 不展示趋势、PR 或动作结论，只保留「缺什么」和记录入口；
- 4–7 个训练日会给出分析，但标注「样本较少，趋势仅供参考」。

## 建议

建议从风险和薄弱项生成，最多 3 条：

- 完成率低：固定每周训练日，先把 4 周补到目标天数；
- 容量下降：先判断是疲劳还是时间问题，疲劳减组保频率，时间紧压缩时长；
- 没有 PR/动作停滞：选一个主项，下次加 2.5kg 或每组多 1 次，连续 2 周；
- 缺部位：每周加 1 次缺失部位，给一个动作示例；
- 单次组数少：每个动作 3 组起，主项 4 组；
- 状态良好：保持频率，主项渐进。

## 局限

- 容量是训练量的近似值，不包含动作幅度、组间休息、RPE、心率与动作质量；
- 自重动作没有重量 PR，系统会用组数趋势代替；
- 一天只记一个动作时，「单次组数偏少」可能只是记录不完整；
- 不分析疼痛、伤病、睡眠、压力与恢复状态；
- 不提供诊断、治疗方案或训练处方。

## 隐私

训练分析完全在浏览器本地计算，不上传额外数据。开启云同步时，云端只保存原始训练记录，分析仍在本机生成。
