# 营养目标计算

目标推荐的目标是**可解释、可复算、有安全边界**，而不是给一个看起来专业的数字。

## 输入

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 性别 | 男 / 女 | BMR 公式常数项 |
| 年龄 | 14–90 岁 | BMR 随年龄下降 |
| 身高 | 120–220 cm | BMR |
| 体重 | 30–250 kg | BMR、训练消耗、蛋白质与脂肪克数 |
| 健身目标 | 减脂 / 维持 / 增肌 | 热量系数 0.85 / 1.0 / 1.10；蛋白系数 2.0 / 1.7 / 1.8 g/kg |
| 每周训练次数 | 0–7 次 | 把单次训练消耗按周均摊 |
| 每次训练时长 | 30 / 45 / 60 / 90 分钟 | 单次训练消耗 |
| 日常活动强度 | 久坐 / 轻度 / 中度 / 高强度 | 非训练活动系数 1.2 / 1.3 / 1.4 / 1.5 |

## 公式

1. **BMR（Mifflin-St Jeor）**
   - 男：`10W + 6.25H − 5A + 5`
   - 女：`10W + 6.25H − 5A − 161`
2. **日常消耗** = `BMR × 活动系数`
3. **训练消耗**：MET 6.0，`kcal/min = 6.0 × 3.5 × W ÷ 200`
   - 单次 = `kcal/min × 时长`
   - 每日 = `单次 × 每周次数 ÷ 7`
4. **TDEE** = `日常消耗 + 每日训练消耗`
5. **目标热量** = `TDEE × 目标系数`，下限 `max(BMR, 男 1500 / 女 1200)`
6. **蛋白质** = `W × 2.0（减脂）/ 1.7（维持）/ 1.8（增肌）`
7. **脂肪** = `W × 0.9`，限制在总热量 20%–35%
8. **碳水** = `(目标热量 − 蛋白质 × 4 − 脂肪 × 9) ÷ 4`，且 ≥ 1.2 g/kg
   - 热量不够时先下调脂肪，保证训练所需碳水

## 算例：70kg / 178cm / 28 岁 / 每周 3 练 / 60 分钟 / 轻度活动 / 维持

| 步骤 | 结果 |
| --- | --- |
| BMR | 1,678 kcal |
| 日常消耗 ×1.3 | 2,181 kcal |
| 训练消耗 | 441 kcal/次 → 189 kcal/天 |
| TDEE | 2,370 kcal |
| 目标热量 ×1.0 | **2,370 kcal** |
| 蛋白质 1.7 g/kg | **119 g**（20% 热量） |
| 脂肪 0.9 g/kg | **63 g**（24% 热量） |
| 碳水（余量） | **332 g**（56% 热量） |
| 折算热量 | 2,371 kcal（与目标差 1 kcal） |
| BMI | 22.1（正常） |

## 安全边界

- BMI < 18.5 选择减脂：自动按维持计算，不鼓励继续减。
- BMI ≥ 28 选择增肌：提示先控制体脂。
- 每周 0 练选择增肌：提示先建立训练习惯。
- 未满 18 岁：提示先咨询专业人士，结果仅供参考。
- 目标热量下限：男性 1,500 kcal、女性 1,200 kcal，且不低于 BMR。

## 展示与取整

- 热量取整到 10 kcal，克数取整到 1 g，因此三大营养素折算热量与目标可能有 ±10 kcal 差异。
- 弹层可展开完整公式；设置页保留最近一次推荐摘要（目标、身体数据、训练频率、计算日期、是否手动调整）。
- 应用推荐只写四项目标值，不改动任何历史训练与饮食记录；四项仍可手调，可恢复推荐。

## 参考与免责

- Mifflin MD, St Jeor ST, et al. A new predictive equation for resting energy expenditure in healthy individuals. *Am J Clin Nutr*. 1990.
- MET 6.0 为力量训练的常见估算值；不同动作、组间休息与强度会带来误差。
- 结果用于个人记录与趋势对比，**不构成医疗或营养建议**；有基础疾病、孕期、进食障碍史等情况请咨询专业人士。
