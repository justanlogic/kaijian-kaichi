# 使用场景

五个真实场景，说明这个产品每天怎么被用。

## 1. 训练日：记完一组，不用算容量

**场景**：晚上练完，只想在手机上快速记完。

1. 打开「训练」→ 今天
2. 选「杠铃深蹲」→ 70kg × 5、80kg × 5、90kg × 5
3. 保存

结果：动作容量自动算成 `70×5 + 80×5 + 90×5 = 1,200 kg`，当日合计与连续记录同步更新；如果超过历史最重，标 **PR**。

## 2. 外卖：搜「麦当劳」直接记

**场景**：中午点了巨无霸套餐，不想自己估。

1. 打开「营养」→ 记录饮食
2. 搜「麦当劳」→ 10 条结果
3. 选「巨无霸」→ 默认 215g / 550 kcal
4. 保存

结果：热量、蛋白质 24.9g、碳水 44.9g、脂肪 29g 一次记完；搜「薯条」也能直接选。

## 3. 烧腊晚餐：叉烧不再是空白

**场景**：广东家庭晚餐，吃了叉烧、白切鸡和米饭。

1. 搜「叉烧」→ 120g
2. 搜「白切鸡」→ 100g
3. 搜「米饭（熟）」→ 150g

结果：叉烧 120g 约 334 kcal / 28.6g 蛋白 / 20.3g 脂肪；烧腊类数据标注了来源与 ±10% 误差，不假装精确。

## 4. 减脂：目标不是拍脑袋

**场景**：70kg，想减脂，每周 3 练，每次 60 分钟。

1. 设置 → 营养目标推荐
2. 填性别、年龄、身高、体重、目标「减脂」、每周 3 次、60 分钟、轻度活动
3. 查看 BMR、TDEE、目标热量、蛋白质 / 碳水 / 脂肪与 BMI
4. 应用到每日目标

结果：目标热量按 TDEE × 0.85 计算，蛋白质 2.0 g/kg，脂肪与碳水有下限；BMI < 18.5 时不会鼓励继续减。

## 5. 换手机：数据带得走

**场景**：从旧手机换到新手机。

- 方式 A：旧手机「设置 → 导出备份」→ 新手机「导入备份」
- 方式 B：两端登录同一个账号 → 云端快照同步

结果：训练、饮食、身体数据、目标与推荐资料一起迁移；导入前会校验结构，坏文件不会覆盖新手机上的数据。
